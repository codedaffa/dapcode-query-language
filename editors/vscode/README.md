# DQL Language Support for VS Code

Ekstensi resmi untuk mendukung sintaksis **DQL (DapCode Query Language)** di Visual Studio Code dan Antigravity IDE.

## Fitur
- **Syntax Highlighting**: Pewarnaan kata kunci kueri (`ambil`, `pilih`, `di_mana`, `gabung`, `urutkan`, `batasi`, `tambah_ke`, `perbarui`, `hapus_dari`).
- **Snippets**: Template instan untuk menulis kueri DQL secara cepat (`ambil`, `ambil_gabung`, `tambah_ke`, `perbarui`, `hapus_dari`).
- **Language Configuration**: Bracket matching otomatis untuk `{}` dan `[]`.
